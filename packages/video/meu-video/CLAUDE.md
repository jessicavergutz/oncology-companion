# Meu Video - Remotion Project

## Overview
Automated video generation project within the Mega Brain monorepo.

## Instructions
- Compositions are in `src/Composition.tsx` (or `.js`).
- Run `npm run dev` from this folder to start the studio.
- Use `npx remotion render` to render.

## Agent Guidance
Follow the patterns in `packages/skills/skills/remotion/SKILL.md` for all development.
